# Sublang Mod

A Minecraft mod built with MultiLoader Template supporting Fabric and NeoForge.

## Requirements

- Java 21

## Setup

1. Clone this repository
2. Run `./gradlew build`

## Project Structure

- `common/` - Shared code (loader-independent)
- `fabric/` - Fabric-specific code
- `neoforge/` - NeoForge-specific code
